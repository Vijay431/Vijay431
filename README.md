I am Vijay Gangatharan, a specialist programmer at Infosys in Bengaluru. ## Projects

- [additional-context-menus](https://github.com/Vijay431/additional-context-menus) — VS Code extension with context-aware right-click menus for refactoring, navigation, and common editor actions. TypeScript.
- [keypress-notifications](https://github.com/Vijay431/keypress-notifications) — VS Code extension that shows on-screen keypress overlays for screencasts, live demos, tutorials, and pair programming. TypeScript.
- [yt-autolike](https://github.com/Vijay431/yt-autolike) — Privacy-first browser extension that likes YouTube videos and Shorts for channels you choose. Runs locally. TypeScript.
- [vscode-extension-template](https://github.com/Vijay431/vscode-extension-template) — Template for VS Code extensions with TypeScript, esbuild, ESLint, and CI.
